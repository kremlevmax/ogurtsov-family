# Референсы дизайна

Кладите сюда скриншоты и примеры визуального стиля, которые владелец
сайта предоставит для оформления. Только изображения-референсы — не
исходники компонентов и не финальные макеты.

После получения скриншотов дизайн-токены в `app/globals.css` и
компоненты в `components/ui/` будут обновлены под них, без изменения
слоя данных. См. [`../DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md).

Пока эта папка пуста — используется временная нейтральная тема.
