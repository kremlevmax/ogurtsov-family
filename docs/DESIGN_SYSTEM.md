# Дизайн-система

## Статус

Финальная тема — «тёплый архив» (warm archive), утверждена по
скриншотам-референсам владельца в `docs/design-references/`
(`family-tree.png`, `top-of-card.png`, `middle-of-card.png`,
`bottom-of-card.png`). Взят визуальный стиль (цвета, типографика,
форма карточек); весь текст на сайте остаётся на русском независимо
от языка референса (CLAUDE.md 3.3).

Если владелец пришлёт новые референсы — меняем значения токенов в
`app/globals.css` и компоненты в `components/ui/`. Слой данных
(`lib/`, `features/`, `server/`) трогать не нужно.

## Принцип

Все цвета, радиусы, тени и отступы задаются через CSS-переменные в
`app/globals.css` (`--color-*`, `--radius-*`, `--shadow-*`,
`--space-*`). Компоненты используют `var(--...)` через Tailwind
arbitrary values (`bg-(--color-bg-elevated)`), а не хардкодят
конкретные hex-значения.

## Палитра («warm archive»)

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--color-bg` | `#f1e9d8` | фон страницы, канва дерева |
| `--color-bg-elevated` | `#faf6ec` | карточки, панели, шапка |
| `--color-bg-inset` | `#ece0c5` | утопленные поля (строка поиска) |
| `--color-fg` | `#2b2118` | основной текст, заголовки |
| `--color-fg-muted` | `#726048` | вторичный текст, эйбрау-подписи |
| `--color-border` | `#ddd0b4` | границы, разделители |
| `--color-accent` | `#9c4a2e` | терракотовый акцент: полоса карточки, аватар, годы жизни, ссылки |
| `--color-accent-fg` | `#ffffff` | текст на акцентном фоне |
| `--color-danger` | `#b3413a` | ошибки, деструктивные действия |

Тёплые архивные тона, светлый фон, без имитации старой бумаги —
приоритет читаемости (CLAUDE.md, раздел 10).

### Палитра родовых веток и подсветки

Не CSS-переменные (цвет — данные конкретного человека, `people.branch_color`
или `people.highlight_color`, см. `docs/DECISIONS.md`), но часть
утверждённой палитры сайта. Восемь пресетов доступны в форме
редактирования (`components/forms/color-preset-swatches.tsx`,
`COLOR_PRESETS`) плюс свободный выбор через `<input type="color">`:

| Цвет | Значение |
| --- | --- |
| тёмно-бирюзовый | `#1a7a6e` |
| золото | `#b58a2e` |
| индиго-фиолет | `#7a4fa3` |
| лесной зелёный | `#3f6b4a` |
| стальной синий | `#2e5f7a` |
| марсала | `#7a3a52` |
| оливково-горчичный | `#8a7a2e` |
| грифельно-серый | `#4a5568` |

В форме редактора человека — три взаимоисключающих варианта:
обычная карточка, «просто выделить эту карточку» (`highlight_color`,
без наследования) или «родоначальник ветки» (`branch_color`,
наследуют все кровные потомки). Правило наследования и раскраска —
`features/tree/branch-colors.ts`, `components/tree/person-node.tsx`.
Супруги/партнёры цвет никогда не наследуют.

## Декоративные акценты

Один сдержанный элемент — `<Ornament />` (`components/ui/ornament.tsx`),
маленький inline-SVG «завиток»-разделитель (fleuron), без внешних
файлов-ассетов (CLAUDE.md 14), красится через `currentColor`.

Разрешено:

- тонкий орнамент-разделитель под шапкой сайта (`components/layout/header.tsx`)
  и над заголовком формы входа (`app/(auth)/login/page.tsx`);
- на мобильном декоративный элемент скрывается (`hidden sm:flex`) —
  на маленьком экране от него больше шума, чем пользы (CLAUDE.md 3.6).

Прямо запрещено (CLAUDE.md 10, «не имитируй старую бумагу, если это
ухудшает читаемость»):

- текстура/фон под старую бумагу где-либо на сайте;
- тяжёлые декоративные рамки, виньетки по углам или орнамент на самих
  полях ввода и внутри `FormSection` — редакторские формы должны
  оставаться максимально простыми и понятными без пояснений
  (CLAUDE.md 12);
- любой декоративный элемент, требующий подгрузки внешнего изображения
  или шрифта сверх уже подключённых `next/font`.

## Типографика

Три роли шрифта через `next/font/google` (наборы `latin` + `cyrillic`):

- `--font-heading` (Prata — заменил Merriweather при переходе на
  направление «Викторианский альбом», см. `docs/DECISIONS.md`: владелец
  выбрал эту пару шрифтов из десяти вариантов на канвасе с мокапами) —
  имена людей, `h1`–`h3`, класс `.font-heading`. В карточке человека имя
  разбито на строки: имя и отчество, затем фамилия — обе жирным, без
  курсива; курсивом (в скобках) — только девичья фамилия, если она есть.
  У Prata только один начертательный вес (400), поэтому акцент на
  заголовках держится на размере и трекинге, а не на жирности.
- `--font-body` (EB Garamond — заменил Lora в той же паре) — основной
  текст сайта, биография, значения в «Основных данных». Задан на
  `body`, других классов не требует. Палитра и решение об охвате
  редизайна (шапка/кнопки/формы/вход) сохранены прежними — сменились
  только эти два шрифта.
- `--font-label` (Geist Mono, был и раньше) — эйбрау-подписи, метки
  полей, годы жизни в карточках дерева, кнопки, ссылка «Вход». Класс
  `.text-label` даёт uppercase + letter-spacing автоматически.

## Компоненты

`components/ui/` — минимальный набор в духе shadcn/ui: `Button`
(варианты `primary`/`secondary`/`ghost`, текст в `.text-label`),
`Input`. Карточка человека в дереве (`components/tree/person-node.tsx`)
имеет цветную полосу сверху (`border-t-4 border-t-(--color-accent)`) и
круглый аватар с инициалами на акцентном фоне — прямая калька с
`family-tree.png`. Новые примитивы добавляются по мере необходимости,
без установки готовой библиотеки компонентов целиком (CLAUDE.md 5.1).

### Фото и документы (Этап 4)

Реализовано в `components/people/media-section.tsx`, в стиле
референсов `middle-of-card.png`/`bottom-of-card.png`: эйбрау-заголовок,
сетка фотографий с полноэкранным просмотром (portal, тот же паттерн,
что и у `PersonDrawer`), файлы — построчно в рамке с бейджем-иконкой
типа файла слева и кнопкой «Скачать» (`.text-label`, акцентный цвет)
справа.

## Обязательные состояния UI

Список из CLAUDE.md, раздел 10, реализуется постепенно по этапам:

- ✅ loading (дерево показывает «Строим дерево…»);
- ✅ empty (дерево без людей);
- ✅ error (дерево не построилось);
- ✅ no search results;
- ✅ missing portrait (инициалы вместо фото);
- ✅ incomplete person (пропуски полей не подставляют ложных данных);
- ✅ upload progress / upload failed (`components/forms/media-upload.tsx`);
- ✅ confirmation before destructive action (`components/forms/delete-person-button.tsx`
  — двухшаговое подтверждение с предупреждением о зависимых связях);
- ✅ offline/network error как отдельное централизованное состояние
  (`components/layout/offline-banner.tsx`, Этап 5) — слушает
  `online`/`offline` события браузера и показывает баннер поверх всего
  сайта; ошибки конкретных Server Actions по-прежнему показываются
  рядом с формой отдельно, баннер покрывает общий случай потери сети.

## Доступность

- фокус видим (`:focus-visible` в `app/globals.css`);
- дерево дублируется доступным списком людей (`<details>` на главной
  странице, `components/tree/family-tree-explorer.tsx`) — каждая
  ссылка ведёт на `/people/<id>`, где родственные связи уже показаны
  как обычные кликабельные ссылки (не canvas), так что связка
  «плоский список + страница человека» полностью доступна с клавиатуры
  и без canvas;
- формы имеют `label` на каждое поле (`components/forms/form-field.tsx`);
- узлы дерева и панель — настоящие `<button>`/`role="dialog"` с
  `aria-label`, не `div` с обработчиком клика.

### Проверка контраста (Этап 5)

Формулы WCAG 2.1, минимум для обычного текста — 4.5:1, для крупного —
3:1. Рассчитано скриптом на реальных hex-значениях токенов:

| Пара | Контраст | Норма |
| --- | --- | --- |
| `--color-fg` на `--color-bg` | 13.0:1 | ✅ |
| `--color-fg-muted` на `--color-bg` | 5.0:1 | ✅ (было 3.45:1 до правки — не проходило) |
| `--color-fg-muted` на `--color-bg-elevated` | 5.6:1 | ✅ |
| `--color-accent` на `--color-bg`/`--color-bg-elevated` | 5.1:1 / 5.7:1 | ✅ |
| `--color-accent-fg` на `--color-accent` | 6.1:1 | ✅ |
| `--color-danger` на `--color-bg`/`--color-bg-elevated` | 4.7:1 / 5.2:1 | ✅ |

`--color-fg-muted` не проходил проверку (использовался для мелкого
вторичного текста вроде подписей и годов жизни, где нужен полный
4.5:1, а не облегчённый порог для крупного текста) — затемнён с
`#8a7a61` до `#726048`, тот же тёплый оттенок, без визуального
конфликта со скриншотами-референсами.
